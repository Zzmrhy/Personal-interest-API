# NASA API Project

This is a website made using NASA's open API for developers (and a bunch of other things I could find)

To start the server you'll first need to do `cd space` or just press **TAB** after typing in **cd**, then you'll need to do `npm run dev`.

Before starting the server, though, you'll need an API key and the packages. To get an API key from NASA click this link (or copy and paste it if it can't be followed) https://api.nasa.gov. To get the packages so the website works correctly type in the terminal `npm install`, there will be a warning (2 minor and 1 significant) after getting the packages installed, to fix them do `npm audit fix` in the terminal.
