This is a project I've been making for about a year now that utilizes NASA's open API for developers and other API's I could find.

The project runs with ReactJS so to start the server (if you need to know) is to type in **cd .\space\\** in the console (or just press Tab) and download necessary packages to allow the site to function using **npm install**. 
Once the packages are installed there might be a warning about several security problems, you can type **npm audit fix** to fix it or fix those errors in the files.
Once all that is fixed and the packages are installed you can then start the server using **npm run dev**
